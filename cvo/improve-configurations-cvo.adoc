= Implementa configuraciones de sistema Cloud Volumes ONTAP bien diseñadas
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Usando las conclusiones y recomendaciones del análisis de configuración, aprovecha NetApp para implementar las mejores prácticas en tus sistemas Cloud Volumes ONTAP que se ejecutan en el almacenamiento de Microsoft Azure. Puedes revisar fácilmente el estado bien arquitectado, conocer los problemas de tus configuraciones y obtener recomendaciones para mejorar la arquitectura de cualquier sistema que no esté optimizado para la fiabilidad, seguridad, eficiencia, rendimiento y coste.

link:configuration-analysis-cvo.html["Conoce el análisis de configuración y el estado de well-architected."]



[[about-this-task]]
== Acerca de esta tarea

El panel de control well-architected analiza a diario las configuraciones de implementación del sistema Cloud Volumes ONTAP en Microsoft Azure. El análisis diario ofrece el estado well-architected, información detallada y recomendaciones.

La conectividad mediante Link o el agente de la consola permite que el panel de control well-architected en la NetApp Console realice un análisis exhaustivo de tus sistemas Cloud Volumes ONTAP para detectar problemas relacionados con el rendimiento, la protección de datos y las configuraciones. Esto asegura que recibas información precisa y recomendaciones para optimizar tus sistemas Cloud Volumes ONTAP.

Los requisitos de configuración del almacenamiento varían. Puedes descartar el análisis de configuraciones específicas que no se apliquen a tu entorno de almacenamiento. Esto te ayuda a evitar alertas innecesarias y resultados de optimización inexactos.



[[before-you-begin]]
== Antes de empezar

* Debes link:https://console.netapp.com/add-working-environment/choose-type["Agregar un sistema Cloud Volumes ONTAP"] a NetApp Console para consultar el estado de well-architected y las recomendaciones sobre problemas de configuración.
* link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html["Deberías implementar un agente de Console"] para obtener el análisis más completo de los recursos de tu sistema.
* Permite la conectividad de red saliente hacia los siguientes puntos finales:
+
** \https://api.workloads.netapp.com
** \https://ws.workloads.bluexp.netapp.com






[[view-recommendations-for-configuration-issues]]
== Ver recomendaciones sobre problemas de configuración

Una vez finalizado el análisis diario, podrás consultar las recomendaciones sobre problemas de configuración. Las recomendaciones explican las mejores prácticas y los posibles riesgos de las configuraciones no optimizadas. También puedes descargar un archivo CSV con las recomendaciones.

.Pasos
. Inicia sesión en link:https://console.netapp.com/home["NetApp Console"^].
. En el menú de la NetApp Console, selecciona *Workloads* y luego *Well-architected*.
. Desde el panel de control de Well-architected, selecciona *Ver* para cualquier configuración.
+
Opcionalmente, selecciona image:button_download.png["Una captura de pantalla del icono de descarga"] para descargar un archivo CSV con las recomendaciones para todas las configuraciones.

. Revisa la recomendación.




[[fix-a-configuration-issue]]
== Solucionar un problema de configuración

Puedes solucionar problemas de configuración en un sistema Cloud Volumes ONTAP o en volúmenes seleccionados de un sistema de archivos. Puedes seleccionar una o varias configuraciones para solucionar.

El proceso de corrección puede provocar tiempos de inactividad de las instancias o interrupciones del servicio. Revisa cada recomendación detenidamente antes de resolver un problema de configuración.

.Pasos
. Inicia sesión en link:https://console.netapp.com/home["NetApp Console"^].
. En el menú de la NetApp Console, selecciona *Workloads* y luego *Well-architected*.
. Desde el panel de control de Well-architected, selecciona *Ver* para cualquier configuración.
+
Asegúrate de revisar la recomendación con atención. La recomendación explica las mejores prácticas y los posibles inconvenientes de las configuraciones no optimizadas.

. Selecciona *Corregir*.
+
Cuando *Ver y corregir* es una opción, selecciona los volúmenes afectados para corregir.

. Revisa el resumen y las acciones pendientes que aparecen en el cuadro de diálogo para saber qué ocurre si solucionas el problema. Algunas operaciones pueden provocar tiempos de inactividad de la instancia o interrupciones del servicio.
. Selecciona *Continuar* para solucionar el problema de configuración.


.Resultado
Workload Factory inicia el proceso para solucionar el problema. Selecciona el menú de configuración de la cuenta y luego selecciona *Tracker* para ver el estado de la operación.



[[dismiss-a-configuration-analysis]]
== Descartar un análisis de configuración

Detén un análisis de configuración de un sistema Cloud Volumes ONTAP o de los volúmenes seleccionados. Puedes reiniciar el análisis cuando lo necesites.

[role="tabbed-block"]
====
.Descartar un análisis de configuración de un sistema
--
.Pasos
. Inicia sesión en link:https://console.netapp.com/home["NetApp Console"^].
. En el menú de la NetApp Console, selecciona *Workloads* y luego *Well-architected*.
. Desde el panel de control de Well-architected, selecciona *Ver* para cualquier configuración.
. En Configuraciones, identifica la configuración que no se aplica a tu entorno y luego selecciona *Desestimar*.
. En el cuadro de diálogo de configuración «Descartar», selecciona *Descartar* para detener el análisis de la configuración.


--
.Descartar un análisis de configuración de un volumen
--
.Pasos
. Inicia sesión en link:https://console.netapp.com/home["NetApp Console"^].
. En el menú de la NetApp Console, selecciona *Workloads* y luego *Well-architected*.
. Desde el panel de control de Well-architected, selecciona *Ver* para cualquier configuración.
. En Configuraciones, identifica la configuración que quieres descartar para los volúmenes seleccionados y luego selecciona *Ver y corregir*.
. Identifica los volúmenes que debes excluir del análisis de configuración.
+
** Para un volumen: selecciona el menú de acciones y luego selecciona *Descartar volumen*.
** Para varios volúmenes: selecciona los volúmenes y luego selecciona *Descartar* junto a Bulk action.


. Selecciona *Descartar* para detener el análisis de la configuración.
. En el cuadro de diálogo «Descartar volúmenes», selecciona *Descartar* para confirmar.


--
====
.Resultado
El análisis de la configuración finaliza para el sistema o los volúmenes seleccionados.

Puedes reactivar el análisis en cualquier momento.



[[reactivate-a-dismissed-configuration-analysis]]
== Reactivar un análisis de configuración descartado

Reactiva en cualquier momento un análisis de configuración descartado para un sistema Cloud Volumes ONTAP. Puedes seleccionar una o varias configuraciones para reactivar.

[role="tabbed-block"]
====
.Reactivar un análisis de configuración de un sistema
--
.Pasos
. Inicia sesión en link:https://console.netapp.com/home["NetApp Console"^].
. En el menú de la NetApp Console, selecciona *Workloads* y luego *Well-architected*.
. Selecciona *Configuraciones descartadas*.
. Identifica la configuración que deseas reactivar y selecciona *Reactivar*.


--
.Reactivar un análisis de configuración de un volumen
--
.Pasos
. Inicia sesión en link:https://console.netapp.com/home["NetApp Console"^].
. En el menú de la NetApp Console, selecciona *Workloads* y luego *Well-architected*.
. Selecciona *Configuraciones descartadas*.
. Identifica el volumen o volúmenes que se van a reactivar a partir del análisis de configuración.
+
** Para un volumen: selecciona el menú de acciones y luego selecciona *Reactivar volumen*.
** Para varios volúmenes: selecciona los volúmenes y luego selecciona *Reactivar* junto a Bulk action.




--
====
.Resultado
El sistema reactiva el análisis de configuración. Se realiza un nuevo análisis cada día.
